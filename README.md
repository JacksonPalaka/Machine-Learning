# Supervised v/s Unsupervised Machine Learning Algorithm 
Supervised learning is a machine learning approach where the model is trained on data that already has correct answers attached to it. In this case, the algorithm learns by comparing its predictions with the known outputs and gradually improves its accuracy. Once trained, the model can predict results for new data it has never seen before. This method is commonly used when the goal is to make clear predictions, such as identifying whether an email is spam or estimating the price of a house.

Unsupervised learning works differently because the data does not come with any labels or answers. Instead of predicting outcomes, the model looks for patterns or similarities within the data on its own. It helps in discovering hidden structures, like grouping similar customers together or reducing complex data into simpler forms. Unsupervised learning is mainly used for exploration and understanding data rather than direct prediction.
